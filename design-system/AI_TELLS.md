# AI tells: patterns Innovation Labs never ships

These are the visual and copy patterns that make a page, deck, post or Reel read as "generated by AI" at a glance. They show up because they are the defaults of AI site builders and template libraries. **They apply to every output in this plugin**: websites, hubs, presentations, one-pagers, social posts, carousels, Stories, Reels, custom images and anything else.

Every maker skill reads this file before building. `human-pass` checks the copy tells. `skills/human-pass/scripts/design_tells.py` scans HTML/CSS/SVG for the visual ones:

```bash
python3 skills/human-pass/scripts/design_tells.py path/to/index.html [more files or folders]
```

**The rule of precedence:** the IL design system wins. Where it explicitly specifies a restrained version of something on this list (the official mesh grounds, a 1–3px card lift, Strategy Route stop markers that grow on hover or selection, the semantic purple accent, the `↗` on "go deeper" links, `Next →` pager controls), that version is allowed and nothing beyond it. Everything else on this list is out by default. A human can make a deliberate, stated exception for one artifact. The model never makes one on its own.

## The list

| # | Tell | What it looks like | IL rule / do this instead |
|---|---|---|---|
| 1 | **Generic icon set everywhere** (Lucide-style line icons) | a uniform outline icon in a rounded tile above every card, nav item and feature | No decorative icon tiles. Use type, numbers, real photos, official IL brand elements or a hand-drawn mark that explains something. An icon only where it does a job (a control, a status) |
| 2 | **Emoji** | 🚀 ✨ 🔥 🎁 in headings, bullets, buttons and stats | None, in any text, on any surface: not in copy, headings, captions or chat bubbles. Chat reactions in Reels use the kit's drawn heart / check, never emoji |
| 3 | **Liquid glass / glassmorphism** | frosted translucent cards, `backdrop-filter: blur`, specular edges on a saturated gradient | Flat IL surfaces (`surface`, `surface-tint`) with `line` borders. Never frosted panels |
| 4 | **Em dashes** | "isn't just a tool — it's a rethink", dashes in every sentence | Commas, full stops, or two sentences. `human-pass` converts them automatically |
| 5 | **Inter / Geist / Space Grotesk** | the default AI-builder type stack | Poppins, IBM Plex Mono, Caveat, exactly as the design system specifies. Never add another family |
| 6 | **Three feature cards in a row** | icon + bold title + grey line, ×3, "Why teams choose us" | Say the one thing that matters, with evidence. If there really are three parts, show them as a sequence, comparison or diagram, not three identical tiles |
| 7 | **Bento grids** | mosaic of rounded tiles with mixed sizes, stats and gradients | IL editorial layout: one statement per screen, modular cards only where people work with data |
| 8 | **Fake terminal window** | traffic-light dots, `npx something init`, "Done in 1.2s" | Show the real product or the real process. Only show a terminal when the content is literally about a command, using the real output |
| 9 | **"It's not X, it's Y"** | "It's not a to-do list. It's a second brain." | State what it is. `human-pass` flags this structure |
| 10 | **No real demos** | "Product screenshot coming soon", gradient placeholder boxes | Real screenshots, real photos, real footage. If none exist, drop the section rather than fake it |
| 11 | **Purple & black** | violet on near-black as "the whole brand" (`#8B5CF6`, `#6D28D9`, `#0A0A0A`) | IL is teal-led Light. Purple is a semantic accent only (`ax`), never a dominant field, never on black |
| 12 | **Radial orbs** | blurred glowing blobs floating on dark backgrounds, "ambient" glow | Only the official IL mesh grounds (`--mesh-*` tokens and the bundled backgrounds), only where the design system allows grounds. No extra blurred orbs or glows |
| 13 | **Dot grids** | a dotted pattern behind content, "structure everywhere" | Already banned by the design system: no dotted grids or micro-lines behind reading content |
| 14 | **Sparkle icons** | ✦ ✨ on "Generate", "AI magic", "Ask X" | Never mark AI with sparkles. Name what the feature does in words |
| 15 | **Animated arrows** | → on every CTA, nudging right on hover | CTAs name the destination in words. `↗` only where the component catalog specifies it ("go deeper" links). Hand-drawn teaching arrows in diagrams and Reels are fine, because they explain something |
| 16 | **Hover animations on everything** | every element lifts 16px and scales 1.05 with a glow | Only what the design system specifies: clickable cards lift 1–3px with `shadow-hover`, buttons change wash. Nothing scales, nothing glows |
| 17 | **Rainbow coloring** | multi-hue gradient text, every card a different pastel border | One palette: teal family plus one semantic accent per artifact. No gradient text. No per-card rainbow |
| 18 | **Accent stripe on cards** (extra, from the IL design system) | a coloured left border on quote, highlight and summary boxes | Never a coloured left border. The 5px top edge on Hub navigation cards is the only accent stripe allowed. Route lines (`--route`) are not stripes |

## Copy tells (checked by `human-pass`)

Em dashes, "It's not X, it's Y", "not only X but also Y", rule-of-three triads, rhetorical one-word questions, emoji, exclamation marks, hype words ("blazing fast", "AI magic", "fort-knox secure", "loved by teams"), round fake stats ("10x", "99.9%", "120+", "10,000+ happy users") with no source, and Title Case headlines.

## Before you ship (every maker)

- [ ] `design_tells.py` run on the output (HTML/CSS/SVG). Every finding is fixed, or is an IL design-system exception named in the review notes.
- [ ] `human-pass` run on the copy.
- [ ] Look at the result as a stranger would: if it could be any AI startup's landing page, it isn't IL yet.
