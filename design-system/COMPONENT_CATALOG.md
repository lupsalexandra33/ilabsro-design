# Innovation Labs component catalog

Synced from the native Claude Design System. These are patterns, not framework-specific React components. Recreate them with the target format's native primitives.

| Component | Purpose | Core rule |
|---|---|---|
| BarChart | Editorial comparison | Takeaway first, direct labels, dashed estimates |
| Button | Primary/secondary/actions | One primary per view; primary uses `action`, not Light `teal` with small white text |
| Card | Modular content/navigation | Medium radius, no shadow at rest; top accent only for nav/link cards |
| Chip | Labels/status/filter | Mono-friendly; status never color-only |
| DeckNav | Phone-first deck control | Segmented progress + chapter + thumb-zone Back/Next |
| Deeper | Link presentation → Hub | `action-soft` pill + destination + ↗ |
| Expand | Progressive disclosure | Keep walls of text behind tap/open |
| Label | Kicker/meta/human aside | IBM Plex Mono for labels; Caveat only as one human accent |
| Panel | Dark/brand emphasis | `teal-deep` / `surface-ink`, calm contrast |
| Route | Mobile journey | Vertical route under 820px; current step purple |
| SectionNav | Local navigation | Sticky scrollable chips |
| Segmented | Equivalent-view switch | Year/Month, Day/Night etc. |
| Sheet | Mobile detail | Bottom sheet, strong close action, `shadow-sheet` |
| Stat | Number-first evidence | Number as visual + one line + source |
| Steps | Ordered process | Purple only for AI/current step |
| Timeline | Dated sequence | Confirmed vs estimated states clearly marked |
| TopNav | Global IL shell | White 2027 logo on teal gradient; active page as white pill |
