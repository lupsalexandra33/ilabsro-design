# Content workflow

Experimental MVP workflow for turning Innovation Labs source material into
source-grounded, reviewable content opportunities.

The current prototype explores:

- source-first content planning;
- theme and angle extraction;
- evaluation for source fidelity, distinctness, clarity, substance and save/share potential;
- human review and selection;
- source-grounded content briefs;
- handoff to the existing content-generation workflow.

## Interactive BPMN

Open [`bpmn.html`](./bpmn.html) to explore the workflow.

Each process step is interactive and includes its inputs, outputs, constraints and guardrails.

## Status

Prototype / work in progress.

The current phase validates the planning and evaluation flow before production automation is introduced.
