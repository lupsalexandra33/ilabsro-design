# v0.4 test plan

Use a fresh Claude chat for each test. For portability, first run with the plugin only and **do not select the native Innovation Labs Design System**.

## 1. Strategy Hub

Attach the strategy source and select `website-maker`.

Prompt intent:
> Turn this into an Innovation Labs 2027 Strategy Hub. Keep the route/map calm and source-grounded. Build the artifact directly.

Pass if:
- full map + mini-map inside the Hub share one stop model;
- no decorative mesh behind the route;
- no generic Open Threads section;
- phone portrait becomes a vertical journey;
- layout is coherent at laptop and phone sizes.

## 2. Route-first deck + yellow accent

Select `presentation-maker` + `brand-elements`.

Prompt intent:
> Make a route-first Innovation Labs presentation from this strategy. Use the yellow accent and link to the current Strategy Hub. Build the deck directly.

Pass if:
- route comes first when the source supports it;
- yellow replaces semantic accent roles without recoloring everything;
- labels on yellow fills use dark text;
- portrait phone gets vertical journey / bottom controls;
- `Lead the room` is absent/hidden if runtime room capability is unavailable;
- final slide links to the Hub URL supplied in the prompt.

## 3. Event-photo social

Select only `insta-post-maker`.

Use the same Demo Day photos and exact event brief from the previous social test.

Pass if:
- photos feel integrated, not pasted as repeated rectangles;
- at least some frames use photo-to-teal blend or direct text overlay where appropriate;
- teal-led Light mode is recognizable;
- people remain focal;
- 0–1 meaningful motif per frame;
- pig/bulb/hourglass are not inserted randomly;
- all frames still form one visual story.

## 4. Campaign social without photos

Select `insta-post-maker` + `brand-elements`.

Prompt intent:
> Turn this update into a 5-card Instagram carousel on the green Innovation Labs template ground. Use one appropriate official brand element per frame at most. Keep one message per frame.

Pass if:
- it uses an approved background family from the plugin;
- text stays on the calm part of the ground;
- logo placement is consistent and readable;
- official SVG assets are used meaningfully rather than approximated;
- it does not imitate the event-photo layout.

## 5. One-pager regression

Select `one-pager-maker` + `formal-lens`.

Prompt intent:
> Make an exact one-page Innovation Labs partner brief from this source.

Pass if:
- exactly one page;
- no invented facts;
- no dotted grid;
- optional branded header/closing band does not reduce print readability.

## Release gate

Only release v0.4 after all five pass or the remaining failures are understood and intentionally accepted.
