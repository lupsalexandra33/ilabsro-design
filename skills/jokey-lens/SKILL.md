# Jokey lens

This is a voice modifier, not an output maker.

- Keep facts, numbers, claims and structure unchanged.
- Use humor sparingly: one light line can be enough.
- Prefer observational/witty over meme-heavy.
- Never joke about sensitive people, failures or unsupported claims.
- If humor weakens clarity or credibility, remove it.
