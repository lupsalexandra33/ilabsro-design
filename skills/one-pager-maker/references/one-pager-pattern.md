# One-pager pattern — v0.4

Recommended anatomy:
1. Brand header + logo + small context label.
2. Strong thesis / title.
3. Short framing paragraph.
4. 3–5 evidence or strategy modules.
5. Clear bottom-line takeaway / CTA.

Useful modules:
- 2–4 large stats;
- a four-step loop;
- 3-column “what changes” block;
- one compact comparison;
- one small timeline;
- one sourced quote/insight.

Brand treatment:
- header may use `grad-brand` or an approved pale template ground;
- closing band may use `grad-accent`;
- one official decorative element may be used at the edge when `brand-elements` is active;
- body reading area stays flat and print-safe.

Avoid:
- reproducing a full report in 8pt text;
- dotted-grid backgrounds;
- decorative mesh behind body copy;
- generic stock photos;
- multiple competing theses;
- unsupported “hero” claims.
