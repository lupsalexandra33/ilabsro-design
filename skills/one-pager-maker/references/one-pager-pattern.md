# One-pager pattern

Recommended anatomy:
1. Logo + small context label.
2. Strong thesis / title.
3. Short framing paragraph.
4. 3–5 evidence or strategy modules.
5. Clear bottom-line takeaway / CTA.

Useful modules:
- 2–4 large stats;
- a four-step loop;
- 3-column “what changes” block;
- one compact comparison;
- one small timeline;
- one quote or insight if sourced.

Avoid:
- reproducing a full report in 8pt text;
- generic stock photos;
- multiple competing theses;
- unsupported “hero” claims.
