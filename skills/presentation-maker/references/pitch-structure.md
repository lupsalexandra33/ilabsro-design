# Strategy presentation structure

## Default slide anatomy

Each slide should have:
- one headline that states the point;
- at most one short explanatory paragraph;
- 1–3 visual/evidence elements;
- optional source note when needed.

## Visual rhythm

Mix:
- dark/deep-teal high-impact slides;
- light editorial evidence slides;
- occasional mesh/network slides;
- data slides where the number is dominant;
- real-person/team insight cards when supplied.

Do not make every slide the same card grid.

## Hub relationship

The deck is a story. The Hub is the reference.

If the audience needs all methodology, research, calendar, people and source detail, send them to the Hub instead of bloating the presentation.
