## What this is

An Innovation Labs comparison visual contrasting two ways of using AI:

asking AI to think in your place versus using AI to pressure-test thinking you already did.

## What it tests

- autonomous visual-direction selection;
- simple comparison-based explanation;
- communicating a conceptual distinction at a glance;
- concise embedded text;
- avoidance of generic human-and-robot collaboration imagery;
- recognizably Innovation Labs visual language.

## Why we kept it

It demonstrates a different explanatory pattern from the sequential “You go first” visual.

Rather than showing a process, it uses direct comparison to make the difference between replacement and challenge immediately understandable.
