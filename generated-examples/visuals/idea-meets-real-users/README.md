# Idea meets real users

**Type:** Narrative illustration
**Status:** Validated example
**Skills:** `brand-image-maker` + `brand-elements`

## What this is

A simple Innovation Labs narrative illustration showing a founder starting with a confident idea and changing it after encountering real user feedback.

## What it tests

- `narrative-illustration` mode;
- simple characters and visual storytelling;
- communicating a concept without a supporting paragraph;
- playful Innovation Labs art direction without generic glossy AI imagery.

## Why we kept it

It demonstrates that `brand-image-maker` can tell a small story rather than only generate diagrams or decorative graphics.

## Files

- `output.png` — generated visual
- `prompt.md` — exact prompt used to generate it

## Notes

The scene is illustrative and does not represent a real founder, programme participant or event.
