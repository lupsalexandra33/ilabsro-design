# Source before prompt

**Type:** Instagram carousel
**Status:** Validated example
**Skills:** `insta-post-maker` + `brand-image-maker` + `brand-elements`

## What this is

A short Innovation Labs carousel explaining the practical idea that better source material and active review often matter more than repeatedly polishing prompt wording.

## What it tests

- coordination between social layout and custom image generation;
- one primary thought per slide;
- hand-drawn explanatory visuals;
- visual variation across a carousel;
- concise editorial copy;
- preservation of Innovation Labs visual identity across multiple frames.

## Why we kept it

It demonstrates the combined social pipeline rather than a single isolated skill.

The drawings carry part of the explanation, allowing the carousel to stay simpler and less text-heavy than a conventional AI-generated social post.

## Files

- `01.png`–`07.png` — generated carousel frames
- `prompt.md` — exact prompt used to generate the carousel

## Notes

This is an editorial capability test.

The carousel should not be interpreted as claiming that prompt wording never matters.
