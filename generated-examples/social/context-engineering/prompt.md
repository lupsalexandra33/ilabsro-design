# Generation prompt

Use the `insta-post-maker`, `brand-image-maker` and `brand-elements` skills from the `ilabsro-design` plugin.

Create an Innovation Labs Instagram carousel based on the approved content brief below.

This is a validated example of the updated social art direction.

## Human-selected visual direction

- visual mode: handdrawn-diagram
- complexity: very-simple
- tone: smart + playful

## Goal

Help the audience understand that better AI output depends substantially on the quality and specificity of the material and domain context they bring, not only on how they word the prompt.

Leave them with one practical habit:

**feed AI real source material, then question what comes back.**

## Audience

Early-stage founders and builders who use AI tools for startup work.

## Selected theme

Output quality depends more on the real material and domain knowledge you bring into the interaction than on repeatedly polishing prompt wording.

## Selected angle

**Stop polishing prompts. Start feeding evidence.**

This is generated editorial framing, not source language.

## Key message

Practitioner guidance suggests that AI output improves when the user brings real evidence, corrections and iteration into the interaction.

Prompt wording may matter, but it should not be treated as the only or primary lever.

## Content requirements

The final carousel must preserve:

1. Prompt wording may matter; do not claim that it does not matter.
2. Real material, evidence, correction and iteration should be central to the message.
3. The practical habit has two parts:
   - bring real source material;
   - interrogate and challenge the output.
4. Use the term **context engineering** as the name for this habit.
5. Preserve a quiet evidence note explaining that this framing comes from practitioner literature rather than peer-reviewed scientific research.

## Content boundaries

Do not:

- say that prompt wording is irrelevant;
- present the claim as scientifically proven;
- describe it as peer-reviewed research;
- invent statistics, percentages or study results;
- define additional technical concepts that are not part of this brief;
- attribute quotations to a specific author;
- name, rank or compare AI models;
- claim Innovation Labs has scientifically validated the principle;
- imply that an illustrative example is a real founder case;
- introduce unrelated research topics.

## Suggested information structure

Use a simple multi-slide progression such as:

1. Common assumption: better wording produces better output.
2. Reframe: wording matters, but what you bring into the interaction matters more.
3. What improves the interaction: real evidence, corrections and iteration.
4. Illustrative comparison: thin input versus input grounded in real material.
5. Practical habit: feed real sources, then question the response.
6. Name the habit: context engineering.
7. Quiet evidence note.
8. Closing takeaway worth saving.

This is information guidance, not a rigid visual template.

## Visual and execution requirements

- build the carousel directly;
- keep one primary thought per slide;
- use more slides if that makes each frame simpler;
- do not default to eyebrow + large headline + paragraph on every slide;
- let drawings, arrows, simple schemas and workshop-like visual language carry part of the explanation;
- sticky-note shapes are allowed when useful, but should not become the default visual primitive;
- keep embedded text in generated visuals very short;
- use varied hand-drawn visual grammar across the carousel;
- the style should feel imperfect, intentional and workshop-like rather than like a polished corporate infographic;
- use Innovation Labs colours;
- preserve the approved factual boundaries;
- do not turn non-critical evidence notes into large disclaimer boxes;
- source/evidence attribution may be quiet or placed in the closing material;
- the post may take a clear editorial position as long as it does not strengthen unsupported factual claims;
- keep the result recognizably Innovation Labs.
