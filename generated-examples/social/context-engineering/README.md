# Context engineering

**Type:** Instagram carousel
**Status:** Validated example
**Skills:** `insta-post-maker` + `brand-image-maker` + `brand-elements`

## What this is

An Innovation Labs carousel about improving AI output by bringing real material, domain context, corrections and iteration into the interaction.

This is the refined version produced after testing slide simplification and the hand-drawn visual system.

## What it tests

- source-bound social execution;
- simple carousel pacing;
- one primary idea per frame;
- varied hand-drawn diagrams and metaphors;
- quiet treatment of non-critical evidence notes;
- coordination between editorial structure and custom visual generation.

## Why we kept it

The result was a useful validation of the updated social art direction: fewer dense slides, less repeated hierarchy and a more distinctive Innovation Labs visual language.
