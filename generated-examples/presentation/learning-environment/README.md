# Useful startup learning environment

**Type:** Presentation
**Status:** Validated example
**Skills:** `presentation-maker` + `brand-image-maker` + `brand-elements`
**Plugin version:** v0.5.0

## What this is

A fictional Innovation Labs conversation deck exploring the question:

“What does a useful startup learning environment actually teach?”

It was created as a capability test for a presentation structure that deliberately differs from the existing Route Deck.

## What it tests

- whether `presentation-maker` can produce a coherent deck without using route-first storytelling;
- one-primary-idea-per-slide pacing;
- variation in slide composition;
- use of diagrams or custom illustrations where they communicate faster than copy;
- Innovation Labs visual consistency across a different presentation archetype;
- concise partner-facing storytelling without generic consulting-deck aesthetics.

## Why we kept it

The deck demonstrates that the presentation system can generalize beyond the existing Route Deck and choose a different narrative pattern while remaining recognizably Innovation Labs.

It also tests coordination between presentation structure and custom visual generation.

## Files

- `index.html` — generated presentation
- `prompt.md` — exact generation prompt
- `assets/` — presentation-specific assets, if applicable

## Notes

This is an illustrative capability-test artifact.

It is not an official Innovation Labs partner deck and does not represent approved partner commitments, programme outcomes, research claims or statistics.
