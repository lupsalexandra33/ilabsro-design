# Build for real problems

**Type:** Website
**Status:** Validated example
**Skills:** `website-maker` + `brand-elements`

## What this is

A fictional Innovation Labs challenge microsite built as a capability test for the website generation system.

It deliberately uses a campaign/editorial structure rather than the Strategy Hub route-first layout.

## What it tests

- whether `website-maker` can produce a different website archetype;
- campaign-oriented information architecture;
- responsive and accessible static output;
- consistent use of the Innovation Labs design system without copying an existing page structure.

## Why we kept it

The result shows that the website system can generalize beyond the Strategy Hub and still remain recognizably Innovation Labs.

## Files

- `index.html` — generated microsite
- `prompt.md` — exact prompt used to generate it

## Notes

This is an illustrative test artifact.

“Build for real problems” is not a real or announced Innovation Labs programme. Any rules, timings, eligibility criteria or examples shown in the page are fictional placeholders.
